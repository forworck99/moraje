# مُراجِع

تطبيق ويب قابل للتثبيت (PWA) لمراجعة حفظ القرآن ومتابعة الطالبة.

- **الرابط:** https://forworck99.github.io/moraje/
- مصحف المدينة (1441هـ) بنفس تخطيط الصفحات والسطور: يس، الزخرف، الدخان، الجاثية.
- تلاوة **العفاسي** و**الحصري** مع تتبّع الآية الجارية، وتكرار الآية أو النطاق، والتقديم والتأخير.
- واجبات (جديد / قديم / حديث / مراجعة)، عدّاد بالسحب مع تأكيد، وتعديل بتأكيد مزدوج.
- تتبّع الوقت النشط لكل صفحة، وسجلّ لا يمكن تعديله أو حذفه، ولوحة متابعة للمعلم.

## البيانات والمصادر
- بيانات الصفحات: حزمة [`quran-qcf4`](https://www.npmjs.com/package/quran-qcf4) (MIT).
- خطوط QCF4 من مجمع الملك فهد، وتُحمَّل من jsDelivr عند الاستخدام ولا تُوزَّع في هذا المستودع.
- الصوت: EveryAyah، مع بديل من verses.quran.com.

## التطوير
```
npm install
npm run build      # يبني app.js من src/
```
للاختبار دون Firebase: افتح `index.html?mock=student` أو `?mock=teacher`.

قواعد الأمان في `firestore.rules`، وتُلصق في Firebase ← Firestore ← Rules.
